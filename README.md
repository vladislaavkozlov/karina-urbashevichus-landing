# Лендинг: Карина Урбашевичус, врач-ортодонт (Ставрополь)

Собран 20.08.2026 по контент-брифу. Чистый HTML/CSS/JS, без сборки и зависимостей.
Открывается двойным кликом по `index.html`, деплоится на любой хостинг копированием папки.

## Структура

```
index.html              единственная страница
assets/css/styles.css   дизайн-система (молочный / шампань / графит)
assets/js/app.js        шапка, мобильное меню, reveal, слайдеры до/после
images/                 фото под лендинг (обработаны из ~/Desktop/karina-urbashevichus-photos)
tools/                  cdp.mjs + check.mjs - автопроверка вёрстки в headless Chrome
```

Превью одним файлом (все картинки внутри, base64): `~/Desktop/karina-landing-preview.html`

## Честность подписей к кейсам

- Кейс «Расширение зубных рядов» - это НЕ MARPE. В архиве врача постов про MARPE нет,
  на фото брекет-система, поэтому в тексте MARPE не упоминается
- Кейс «Подготовка к ортогнатической хирургии» подписан как промежуточный этап,
  а не финал: справа пациент с брекетами, лечение продолжается
- Срок «18 месяцев» указан только там, где он есть в подписи врача

## Контакты записи

В `assets/js/app.js` сверху лежит объект `CONTACTS`. Как только появятся номер и мессенджеры -
впишите их туда, кнопки в финальном блоке пересоберутся сами в приоритете
WhatsApp → Instagram → Telegram, телефон отдельной кнопкой. Пустое поле = кнопки нет.
Сейчас заполнен только Instagram Direct.

## Чего на сайте нет и почему

1. **Телефон / WhatsApp / Telegram** - контактов не передавали, работает только Instagram Direct
2. **Форма записи** - без телефона и без бэкенда форма была бы нерабочей кнопкой
3. **Конкретика обучения** (курсы, преподаватели, годы) - данных от врача нет
4. **Реквизиты и лицензия** - для медицинского сайта по закону нужны:
   название юрлица/ИП, ИНН, номер лицензии, политика обработки перс. данных,
   согласие на обработку в форме. Данных нет, заглушки не ставил

## Юридическое (проверить ДО публикации)

Фото пациентов (лица и внутриротовые снимки) требуют письменных согласий на публикацию
в коммерческих целях - 152-ФЗ. Врач публиковала их в Instagram, но это не заменяет согласия
на размещение на сайте клиники.

## Автопроверка

```
node tools/check.mjs
```
Проверяет: мобильное меню, слайдеры, появление блоков, якоря, битые картинки, загрузку шрифтов.
Последний прогон: всё зелёное, горизонтального скролла на 390 px нет.
