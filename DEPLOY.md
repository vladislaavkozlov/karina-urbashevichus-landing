# Как посадить сайт на домен клиники

## Вариант A - GitHub Pages (рекомендую)

Сайт статический, база данных и серверный код ему не нужны. Pages даёт бесплатный хостинг,
бесплатный HTTPS-сертификат с автопродлением и раздачу через мировой CDN.

**Шаг 1.** В кабинете webnames.ru у домена прописать DNS-записи:

| Тип | Имя | Значение |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | vladislaavkozlov.github.io. |

**Шаг 2.** Запустить `bash tools/setup-domain.sh <домен>` - скрипт добавит файл CNAME,
пропишет домен в настройках Pages, дождётся сертификата и включит принудительный HTTPS.

Обновление DNS у регистратора занимает от 15 минут до нескольких часов.

## Вариант B - Amvera

Нужен, если позже появится серверная часть (онлайн-запись с базой, личный кабинет, приём заявок формой).
Для статики это лишние ~170-290₽ в месяц.

Порядок: создать в кабинете приложение → добавить в него SSH-ключ для деплоя →
положить в корень `amvera.yml` со статик-раздачей → запушить в ветку `master` встроенного git →
на вкладке «Домены» привязать домен → в webnames прописать A-запись на IP, который выдаст Amvera.

Шаги в кабинете (создание приложения, добавление ключа, привязка домена) делаются руками
владельцем аккаунта - через API они недоступны.

## Перед боевым запуском

1. Удалить из `index.html` строку `<meta name="robots" content="noindex, nofollow">` -
   пока она стоит, сайт не попадает в поиск
2. Подтвердить письменные согласия пациентов на публикацию фото (152-ФЗ)
3. Добавить реквизиты и номер лицензии в подвал
4. Вписать телефон и WhatsApp в `CONTACTS` в `assets/js/app.js`
